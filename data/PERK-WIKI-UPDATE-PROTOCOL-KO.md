# 퍼크 위키 업데이트 필수 체크리스트

퍼크 정보를 위키에 추가·수정할 때 아래 네 단계를 반드시 순서대로 검증한다. 네 단계 중 하나라도 근거가 없거나 불일치하면 그 퍼크를 공개하지 않고 업데이트 완료로 처리하지 않는다. 자세한 규칙과 설명 범위는 프로젝트의 `Docs/WIKI-UPDATE-PROTOCOL-KO.md`를 따른다.

**기준 우선순위:** 실행 코드와 활성 설정이 게임 효과의 절대 기준이다. EN/INT·KOR·JPN 현지화가 코드와 다르면 먼저 코드를 기준으로 현지화를 수정하고, 위키는 수정된 현지화와 코드 검증 결과를 반영한다. 순서는 `코드/활성 설정 → 현지화 → 위키`이며, 오래된 번역이나 위키 설명을 사실 기준으로 삼지 않는다. 수정된 현지화가 포함된 공개 빌드 전에는 위키를 공개하지 않는다.

## 1. 퍼크 이미지 일치 여부

- 현재 SDK에서 편집한 `C:\Users\yss19\Documents\My Games\KillingFloor2\KFGame\Unpublished\BrewedPC\ZedternalTemperedPerkIcons.upk`의 실제 export와 텍스처를 확인한다.
- 아이콘이 해당 퍼크를 나타내는지, 레벨별 변형이 맞는지 직접 확인한다. 파일명/경로 존재만으로 통과시키지 않는다.
- 실제로 연결된 UPK 텍스처와 위키에서 보여줄 이미지 경로를 함께 기록한다.

## 2. 패시브·캡스톤 스펙 일치 여부

- 현재 등록·효과 코드와 활성 설정에서 패시브 및 캡스톤의 효과, 수치, 단위, 레벨별 변화, 대상과 발동 조건을 확인한다.
- 중첩·상한·조건 충돌 등 실제 동작을 위키 데이터와 대조한다.

## 3. 활성 스킬만: 목록·설명·숫자 스탯 대조

- 최신 런타임에서 실제 등록되고 구매 가능한 스킬만 나열한다. 비활성·은퇴·삭제·미등록 스킬은 제외한다.
- 활성 스킬별 이름과 EN/INT·KOR·JPN 설명, 수치·단위, 발동 조건, 확률, 지속시간, 쿨다운, 중첩/상한, 일반·디럭스 차이를 먼저 코드와 설정에 대조한다. 불일치 현지화는 코드 기준으로 수정하고, 위키에는 수정된 현지화 문구를 사용한다.
- 스킬 개수와 메뉴 목록도 대조한다.

## 4. 구현 코드 상세 정보

- 낡은 위키 문구를 반복하지 말고 현행 구현을 읽어 설명한다.
- 해당 기능의 진입점, 서버 권한/클라이언트 복제, 적용 대상과 범위, 피해/스탯 계산 순서, 무기·피해 타입 제한, 확률·타이머·지속시간·쿨다운·중첩·상한, UI·로그 및 예외를 독자 친화적으로 공개한다.
- 고정 양식은 없지만 확인된 코드 수준의 동작을 빠뜨리지 않는다. 근거를 찾지 못한 동작은 추측하지 않는다.

## 기록 및 통과 기준

각 퍼크의 작업 기록에 네 단계별 `통과/보류`, 확인한 UPK export·소스 코드·설정 키·KOR 현지화·위키 이미지 경로, 수정한 불일치를 남긴다. 네 단계 모두 통과해야 해당 퍼크 문서를 배포 대상으로 삼는다.
